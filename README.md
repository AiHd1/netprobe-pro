# NetProbe Pro

Чем отличается от обычного сканера
+
Оценка уровня опасности
Каждый открытый порт получает уровень: CRITICAL / HIGH / MEDIUM / LOW. Объясняет почему это опасно.
+
Автоматические рекомендации
Программа сама пишет что нужно исправить — без технических знаний у клиента.
+
Параллельное сканирование
100 потоков одновременно — 1000 портов за 10-15 секунд.
+
Экспорт отчётов
JSON и CSV — клиент может открыть в Excel или передать своему IT-специалисту.
+
Читает баннеры
Пытается получить информацию о программе на порту — версию сервера и т.д.

Кому нужно
* Малый бизнес: Проверить свой сервер перед запуском сайта
* Фрилансеры: Быстрый аудит для клиентов как услуга
* Devops: Проверка после деплоя — не открылось ли лишнее
* Студенты: Практика кибербезопасности в лаборатории

Установка
1. Скачать файл
git clone https://github.com/AiHd1/netprobe-pro
2. Запустить (Python 3.6+)
python port_scanner.py 192.168.1.1
3. Или запустить интерактивно
python port_scanner.py
→ Введите IP или домен: example.com

Требования
✓ Python 3.6 или новее
✓ Нет сторонних библиотек — только стандартная библиотека Python
✓ Работает на Windows, macOS, Linux
! Сканируй только свои серверы или серверы с разрешения владельца
